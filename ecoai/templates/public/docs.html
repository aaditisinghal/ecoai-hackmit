Documentation

API reference, optimization strategies, and how the carbon estimate is built.

Authentication

Every API request carries your key in an X-API-Key header.

curl -X POST {{ base_url }}/api/v1/optimize \
  -H "X-API-Key: $ECOAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Could you please summarize this?"}'

Authorization: Bearer <key> works too. Keys are stored as a SHA-256 digest and displayed once at creation, so keep yours somewhere safe — it cannot be recovered, only replaced.

Strategies

Each level includes everything below it.

StrategyDoes
conservative Whitespace tidying and pure politeness ("please", "kindly", "thanks in advance").
balanced Adds hedges ("could you please", "I was wondering if you could"), intensifiers ("very", "really"), and verbose-to-concise substitutions ("in order to" → "to").
aggressive Adds meta-instruction removal and de-duplication of repeated sentences.

What is never rewritten

These spans are extracted before any rewriting and restored verbatim:

  • Fenced ``` blocks, indented code, and inline `code`
  • URLs and email addresses
  • Template placeholders: {{ '{{x}}' }}, {{ '{x}' }}, ${x}, %(x)s, <PLACEHOLDER>

Numbers are checked separately: if any digit sequence in the input is missing from the output, the retention score is capped and a warning is attached.

Retention score

The fraction of content tokens — words that are not stopwords, plus every number and protected span — that survive optimization. 1.0 means nothing of substance was dropped.

It is a lexical measure, not an embedding similarity, and it does not claim to be one. Filler words are in the stopword list on purpose, so removing them cannot depress the score.

How the carbon estimate works

tokens → FLOPs → joules → kWh → grams CO₂e

  1. FLOPs per token — 2 × active_parameters, the standard transformer forward-pass estimate (Kaplan et al., 2020).
  2. Joules per FLOP — from accelerator throughput per watt. Default assumes an H100 SXM at ~700 W sustaining ~400 TFLOP/s bf16.
  3. PUE — datacenter overhead multiplier, default 1.12.
  4. Grid intensity — grams CO₂e per kWh for the region.

Every coefficient is an environment variable. Absolute values depend on inputs no one outside the provider can observe; what the estimate is good for is comparing a prompt against itself before and after optimization.

Rate limits

API requests, sign-ins, sign-ups and report emails each have their own limit, configured per deployment. Responses carry X-RateLimit-* headers, and exceeding a limit returns 429 with a JSON body.
