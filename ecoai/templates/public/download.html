Python SDK

A single file with one dependency. It calls this portal's API, so the SDK and the Studio always agree on what an optimization produced.

Install

Download the module and drop it next to your code.

Download ecoai_sdk.py 

pip install requests

Use it

from ecoai_sdk import EcoAI

eco = EcoAI(
    api_key="ecoai_...",              # or set ECOAI_API_KEY
    base_url="{{ base_url }}",
)

result = eco.optimize(
    "Could you please kindly write a very detailed summary?",
    strategy="balanced",
    model="gpt-4o-mini",
    region="eu-north-1",
)

print(result.optimized)
print(f"{result.tokens_saved} tokens saved ({result.reduction_ratio:.1%})")
print(f"{result.co2_g_saved:.6f} g CO2e avoided")
print(f"retention {result.retention_score:.2f}")

Batch reporting

Already optimizing elsewhere? Send receipts directly. Ingestion is idempotent on receipt_id, so retries never double-count. 

eco.send_receipts([
    {
        "receipt_id": "run-42",
        "tokens_before": 1200,
        "tokens_after": 890,
        "model": "gpt-4o",
        "region": "us-west-2",
    }
])
